# 🕹️ Arcade Multiverse 3-en-1

Plataforma Arcade web unificada en HTML5 Canvas + JavaScript que incluye **3 juegos completos** accesibles desde un mismo menú interactivo:

1. **🏎️ Pixel Arena Cars** (`games/pixel-arena-cars/`) — Batallas acrobáticas 2D estilo *Drive Ahead!* con 8 estadios interactivos, modo 1v1, 2 Jugadores, Rey de la Colina, Misiones y Garaje con Ruleta.
2. **⚽ Head Soccer 2D Championship** (`games/head-soccer/`) — Fútbol arcade con animación esquelética 2D, Super Tiros elementales, nocauts, Copa Mundial, Supervivencia y Gol de Oro.
3. **💥 Shōnen Smash** (`games/shonen-smash/`) — Pelea de plataformas para 1 a 4 jugadores (teclado y mandos) con 11 luchadores anime, transformaciones, Esfera del Dragón y ataques definitivos.

## 🚀 Cómo publicarlo en GitHub Pages

1. Sube el contenido de esta carpeta (`ArcadeHub`) a un repositorio nuevo en GitHub.
2. En tu repositorio de GitHub, entra a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch** → rama `main` y carpeta `/ (root)` → **Save**.
4. ¡Listo! Tu consola con los 3 juegos quedará publicada en `https://<tu-usuario>.github.io/<tu-repositorio>/`.
